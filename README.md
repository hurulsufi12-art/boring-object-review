A single funny, true one-line review of the dullest everyday object I could
name — a plain white sock — written by `main.py` to `/output/entry.txt`.

## The review

> My plain white sock lost its twin to the dryer years ago; now it just goes grey alone, holding up one foot and a lifelong grudge.

129 characters, one line. The joke is the sock's own dullness: its twin
really does vanish in the wash, the survivor really does go grey, and its
whole job really is holding up one foot.

## Run

```sh
python3 main.py
```

Writes the review to `/output/entry.txt` (UTF-8, no trailing newline).
The program validates the review first — 1–200 characters, not only
whitespace, single line — and exits non-zero without writing anything if
it fails validation.
